# ☕ PolyCafe - Coffee Shop Management System

[![Framework](https://img.shields.io/badge/Framework-.NET%20Framework%204.7.2-blueviolet)](https://dotnet.microsoft.com/)
[![Database](https://img.shields.io/badge/Database-SQL%20Server-red)](https://www.microsoft.com/en-us/sql-server/)
[![Language](https://img.shields.io/badge/Language-C%23-green)](https://learn.microsoft.com/en-us/dotnet/csharp/)

**PolyCafe** là một ứng dụng quản lý quán cafe được xây dựng bằng ngôn ngữ **C#** trên nền tảng **Windows Forms**. Dự án tập trung vào việc tối ưu hóa quy trình gọi món, quản lý bàn và theo dõi doanh thu cho các quán cafe quy mô vừa và nhỏ.

---

## 🌟 Tính năng nổi bật

- [x] **Quản lý sơ đồ bàn:** Theo dõi trạng thái bàn (Trống / Có khách) theo thời gian thực.
- [x] **Quản lý Thực đơn (Menu):** Thêm, xóa, sửa các danh mục món ăn và đồ uống linh hoạt.
- [x] **Xử lý đơn hàng:** Giao diện gọi món (Order) trực quan, hỗ trợ chuyển bàn, gộp bàn và giảm giá.
- [x] **Thanh toán & Hóa đơn:** Tính toán hóa đơn tự động và lưu trữ lịch sử giao dịch.
- [x] **Báo cáo doanh thu:** Thống kê doanh thu theo ngày/tháng/năm bằng các truy vấn SQL tối ưu.
- [x] **Bảo mật:** Hệ thống đăng nhập và phân quyền giữa Quản lý (Admin) và Nhân viên.

## 🛠 Công nghệ sử dụng

- **Ngôn ngữ:** C# (.NET)
- **Giao diện:** Windows Forms (WinForms)
- **Cơ sở dữ liệu:** Microsoft SQL Server
- **Kiến trúc:** 3-Layer Architecture (DAO - DTO - BUS) để đảm bảo tính dễ bảo trì và mở rộng.
